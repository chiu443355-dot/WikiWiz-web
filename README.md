---

## 🚀 Deploy to GitHub Pages (2 minutes)

```bash
# Step 1: Go to this folder in terminal
cd apex-trader

# Step 2: Initialize git
git init
git add .
git commit -m "🚀 Launch Apex Trader Academy"

# Step 3: Create repo on github.com, then:
git remote add origin https://github.com/YOUR_USERNAME/apex-trader.git
git branch -M main
git push -u origin main

# Step 4: On GitHub → Settings → Pages → Source: main → / (root) → Save
# Live in 60 seconds at: https://YOUR_USERNAME.github.io/apex-trader/
```
